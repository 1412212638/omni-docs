# 可接受使用政策

生效日期：2026 年 3 月 25 日

更新日期：2026 年 8 月 17 日

本《可接受使用政策》补充《[用户协议](/zh/legal/terms)》，适用于您通过 OmniRouters 网站、控制台、API、文档和相关工具开展的全部活动。

## 1. 基本原则

您仅可在合法、正当、已获授权且符合本政策的前提下使用 OmniRouters。您不得通过平台实施、协助、放大或规避任何违法、侵权、欺诈或滥用行为。

## 2. 禁止行为

### 2.1 违法与侵权内容

您不得利用 OmniRouters 生成、存储、处理、传播或协助传播以下内容：

- 违法内容、侵权内容、虚假宣传、诈骗信息或侵犯第三方合法权益的材料
- 恶意诽谤、骚扰、威胁、仇恨、暴力煽动或明显有害内容
- 恶意冒充、欺骗性身份伪装、误导性深度伪造或非授权身份仿冒

### 2.2 安全与平台滥用

您不得：

- 绕过认证、速率限制、权限控制或其他安全措施
- 扫描、探测、攻击、压测、抓取、镜像或干扰平台、模型路由或相关基础设施
- 传播恶意代码、木马、勒索软件、僵尸网络控制代码或其他恶意程序
- 进行撞库、窃取凭证、批量试错、盗刷或其他账户攻击行为

### 2.3 儿童安全与 CSAM 零容忍

OmniRouters 对儿童性虐待材料（Child Sexual Abuse Material，CSAM）及任何儿童性剥削或性化行为实行零容忍。无论内容是否真实、合成、编辑、深度伪造，或全部或部分由 AI 生成，您均不得利用 OmniRouters：

- 生成、编辑、转换、上传、存储、传播、展示、索取、交易或协助获取 CSAM
- 描绘、模拟、暗示或美化涉及未满 18 周岁者的性行为、性剥削、性暴力、裸露性内容或性化角色扮演
- 对未成年人实施诱骗、性勒索、性骚扰、性交易、人口贩运或其他剥削行为
- 尝试规避安全措施、年龄保护、内容分类器、哈希匹配、审核或举报机制，以生成或传播上述内容
- 使用未成年人的真实或合成形象、声音、身份或个人信息制作性化内容，包括所谓“虚构”“艺术”“角色扮演”或“年龄模糊”的内容

如内容中的人物年龄不明确，但根据外观、上下文、提示词、元数据或其他信息有合理理由认为其可能未满 18 周岁，我们可按未成年人内容处理。为保护儿童安全，我们可不经事先通知立即阻断请求、限制相关功能、撤销 API Key、暂停或永久终止账户、保存必要记录，并在适用法律要求或允许时向主管机关、执法机构或公认的儿童保护举报机构报告。

### 2.4 欺诈与不当业务行为

您不得利用 OmniRouters 从事：

- 钓鱼、冒充客服、支付欺诈、营销诈骗、刷量、垃圾信息传播
- 隐藏或伪造真实调用来源、计费责任或业务主体
- 违反适用支付规则、出口管制、制裁要求或行业监管义务的活动

### 2.5 高风险与受限制场景

对于可能影响个人重大权益的场景，您应进行独立评估并保持人工复核。未经充分保障，您不得将 OmniRouters 输出直接作为以下事项的唯一依据：

- 就业、解雇、绩效考核、教育录取
- 贷款、信用、保险、住房、公共服务资格
- 医疗诊断、治疗决策、法律意见或执法判断
- 身份验证、实时监控、敏感画像或其他高风险自动化决策

### 2.6 知识产权与数据合规

您不得：

- 上传、传输或处理您无权使用的数据、代码、文档、模型或素材
- 在无适当法律基础、授权或通知的情况下处理第三方个人信息
- 要求 OmniRouters 规避平台限制、第三方规则或监管义务

## 3. 违规调查与处置机制

我们可能通过自动化检测、哈希或特征匹配、异常行为分析、人工复核、用户举报、第三方通知及法律要求发现和调查潜在违规。我们会综合考虑内容或行为的性质、严重程度、影响范围、用户意图、是否重复违规、账户历史、紧迫风险及适用法律要求，采取一项或多项措施：

- 提示教育、警告、要求删除或纠正内容、要求补充说明或整改
- 阻断、拒绝或删除相关请求、输入、输出、文件、公开分享链接或其他内容
- 限制模型、媒体生成、文件上传、分享、调用速率、并发、地区或其他功能
- 暂停或撤销 API Key、令牌、账户或相关访问权限
- 对严重、故意、重复或规避安全措施的违规永久终止账户和服务
- 依据《[用户协议](/zh/legal/terms)》和《[计费与退款说明](/zh/legal/billing-refund)》冻结或拒绝相关退款申请
- 保存必要日志和证据，并在适用法律要求或允许时向主管机关、执法机构、受影响方、上游服务商或公认举报机构披露或报告

对于一般且可纠正的首次违规，我们可视情况先行警告或要求整改；对于 CSAM、儿童性剥削、紧迫人身危险、重大欺诈、恶意软件、系统攻击、规避安全措施或重复违规，我们可不经事先警告立即采取限制、暂停、终止、证据保全和报告措施。采取措施的范围和期限可根据风险变化进行调整。

## 4. 举报渠道与处理时限

任何人均可通过以下渠道举报涉嫌违反本政策的内容或行为：

- 举报邮箱：`support@omnirouters.com`
- 建议邮件主题：“内容安全举报”；涉及儿童安全时请注明“CSAM 举报”

举报时请尽量提供：相关页面或资源 URL、模型名称、请求 ID、账户或 API Key 名称（请勿提供完整密钥）、发生时间和时区、问题描述，以及能够帮助定位的脱敏截图或日志。举报 CSAM 时，请勿下载、复制、转发或在邮件中附上疑似违法材料；仅提供可定位信息，并在存在即时人身危险时同时联系当地执法或紧急服务机构。

在举报信息足以识别问题且举报人提供有效联系方式的情况下，我们承诺：

- 在收到举报后 24 小时内确认收件
- 在收到举报后 72 小时内完成初步审查，并在适当情况下告知是否已采取或正在评估处置措施
- 涉及 CSAM、儿童即时危险或其他紧急安全风险的举报将被优先处理，并在合理可行的最短时间内采取临时保护措施

复杂案件、跨平台取证、身份核验、法律要求或第三方协查可能需要更长时间。此时，我们会在合理范围内向举报人说明进度；法律禁止披露、保护受害者、调查保密或防止规避安全措施所必需的情况除外。上述时限是处理目标，不限制我们依法立即采取措施，也不构成对最终结论或处理结果的保证。
