# AI应用

这里会持续收录与 OmniRouters 生态相关的 AI 应用、桌面工具和集成方案。

## 当前收录

- [AionUi](/zh/ai-apps/aionui)
  免费开源的桌面办公 Agent，支持多种 AI 代理与本地化工作流。
- [CC Switch](/zh/ai-apps/cc-switch)
  跨平台 AI CLI 统一管理工具，适合集中管理 Claude Code、Codex 和 Gemini CLI 的 Provider 配置。
- [Codex 配置教程](/zh/ai-apps/codex)
  通过 `~/.codex/config.toml` 配置 Codex 使用 OmniRouters OpenAI Compatible API。
- [Claude Code 配置教程](/zh/ai-apps/claude-code)
  通过本地 `settings.json` 和 onboarding 配置，让 Claude Code 走 OmniRouters 网关。
